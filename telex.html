TELEX.

Short scripts typed on the pads. They play TELEX's test voice and send MIDI notes and CC to the rack. Ten scripts of six lines each, a metro that runs one of them on a clock, and four lists of numbers to step through.

tracker-box 0.16.3 · the language is Teletype's, cut down and pointed at MIDI

First five minutes

  1. Open TELEX: Song, then Down to TELEX, F1. The tabs across the top are the ten scripts. The encoder picks one.

  2. On script 1, line 1, type this on the pads and press Insert to enter it:

    NOTE 60

    Press F1. You hear middle C. F1–F8 run scripts 1–8.

  3. Change the line to this, Insert, and press F1 a few times. Each press is a different note.

    NOTE + 60 RAND 12

  4. Turn the encoder to M, the metro's script, and enter:

    NOTE DEG RAND 7

    Press Play. M now runs every 500 ms, picking a random note of the scale. Play again stops it.

  5. Make it sparser: change M's line to this and Insert.

    PROB 40: NOTE DEG RAND 14

  6. Make it faster: turn to script 1, go to line 2 (Down), enter this and press F1.

    M 125

    Settings like this belong in I, which runs once when a scene loads.

  7. Keep it: Pattern opens SCENES. Choose an empty slot and press F2.

How a line reads

Read a line from the right. Each word takes the values to its right and gives back one value. Numbers are just values.

NOTE+60RAND12
12a value RANDtakes 12, gives a random 0..12, say 7 60a value +takes 60 and 7, gives 67 NOTEtakes 67 and plays it

Setting and reading. A variable or setting that starts its line with a value after it is set: X 5. Anywhere else it is read: NOTE X. The same goes for M, VEL, ROOT and the other settings.

Several commands. Split them with ;, as in X + X 1; Y 2.

Mods. A line may start with a mod, its values, then : and the command it controls: PROB 30: NOTE 72. One mod a line.

Numbers are whole, −32768 to 32767. Division by zero gives 0. Lower case types as capitals.

Playing

KeyDoes
F1–F8Run scripts 1–8 once.
Shift+F1Init: start from nothing. Press it twice. Every script and pattern is emptied, the settings go back to their defaults and the metro stops. The scenes saved on the card stay.

Shift+PlayRuns I again now, so a change to its settings takes effect. Nothing else resets: variables, patterns and the metro stay as they are.
Shift+F8The encoder sets the MIDI out channel: off, 1–16. Notes and CC go out on DIN and USB. Any other key, or three seconds without turning, gives the encoder back to the scripts.
Master+Shift+encoderTELEX's output level, as on every mode.
PatternOpens SCENES.
RecOpens RACK: the LFOs and clocks as they run. Rec again goes back.

SCENES

KeyDoes
Up Down, encoderChoose a slot, 01–16. Left Right jump between the columns.
F1Loads the slot. Variables reset, I runs, and you are back at the scripts. Press Play to start the metro.

The scene you are playing is saved by itself and comes back at power-up. Slots are files on the card: Scripts/01.txt to 16.txt.

The screen

A dot on a tab lights each time that script runs. On the right: the variables, then the pattern (P0 3/8 55 is pattern 0, step 3 of 8, value 55), the key and scale, the note settings, the voice settings, and six squares that light while each voice sounds.

Mods

A mod starts the line and decides whether, when or how often the command after its : runs.

ModThe command runsExample
PROB n:n % of the times the line is reached.PROB 30: NOTE 72
IF x:When x is not 0.IF GT X 3: NOTE 72
ELIF x:When no IF or ELIF above it in this run took, and x is not 0.ELIF EQ X 3: NOTE 67
ELSE:When no IF or ELIF above it took.ELSE: NOTE 60
L a b:Once for each I from a to b (up or down, at most 64 times).L 1 4: NOTE + 60 I
EVERY n:Every nth time the line is reached.EVERY 4: VEL 127
SKIP n:Every time except every nth.SKIP 3: NOTE 48
OTHER:When the EVERY or SKIP above it did not run.OTHER: VEL 60
DEL ms:Later, ms from now (16 can wait at once).DEL 250: NOTE 72

Instruments

INST n plays the instruments on the card, the way WAVE picks the test voice's shape. n is the number a folder in Instruments/ starts with, the same number a MIDI program change uses. You can switch on every line: INST 3; NOTE 72 then INST 15; NOTE DEG RAND 7 plays the bells and the Rhodes on the same tick.

  • Four at once. The first time a scene names an instrument (best in I), it loads from the card in a second or two. Its notes are silent until it's in. The inst row on the right shows each slot: filled when loaded, outlined while loading, red when there's no such folder. A fifth instrument takes the place of the one played longest ago.
  • One-shots, mono, panned. A note picks the instrument's nearest zone and plays it out. Each zone is kept mono, so it takes half the memory and PAN places every note cleanly. WAVE, DEC and TONE only shape the test voice.
  • Memory is borrowed. While TELEX is in use its instruments live in SAMPLER's memory and GLITCH's pool. Leave TELEX and they go back: SAMPLER reloads its sound in the background, GLITCH and LOOP start empty (an unsaved LOOP reel is lost). Come back and the instruments load again.
  • A big multisample won't all fit. Each instrument gets 8 zones at most, loaded from the one nearest C3 outwards, so it keeps a spread across its range.

Rack

TELEX has its own small modular rack: four LFOs and four clocks. Like modules patched into a Teletype, each one can fire a script on its own timing and give a value scripts can read. An LFO can also stream itself out as a MIDI CC, which turns TELEX into a modulation source for the rack. Set them from the scripts, usually in I. Rec shows them running.

Play starts and stops everything that fires scripts: the metro, the clocks and the LFOs' cycle triggers. The LFOs themselves never stop moving, so their values and CC streams carry on, like a free-running LFO module.

Errors and limits

You seeIt means
unknown word FOOA word TELEX does not have, or a typo.
NOTE needs more valuesA word is missing the values to its right: NOTE alone.
a value left over (set a variable, or NOTE it)Something gives a value nothing uses: X alone, or 1 2.
a ':' after the mod's valuesA mod without its colon: PROB 50 NOTE 60.
DEL goes first, with ':' after itA mod in the middle of a line. Give it its own line.
nothing after ':'A mod with no command.
too longOver 40 characters.
too much at onceThe scripts needed more than the box can do in one block of audio, so the rest of that block's work was cut. Usually a big L loop calling SCRIPT.

Ten scripts, six lines each, 40 characters a line. Six voices: a seventh note takes the oldest. The scripts get about 990 words of work per block of audio (less when the delay or reverb runs), so the box never overloads.

Scene files

A scene is a text file on the card, Scripts/01.txt to 16.txt. You can write one on the computer, or describe a scene to Claude and get one written. The layout is Teletype's: the title on the first line, then each script under its mark.

Scripts/02.txt

steps
steps: a pattern walked, euclid accents

#1
P.I 0; T 0; NOTE P 0

#M
NOTE P.NEXT
IF ER 5 16 T: NOTE + P.HERE 12
T + T 1

#I
M / BEAT 4
WAVE 2; DEC 180; TONE 70

#P
0: 48 51 55 58 60 55 51 63

TELEX borrows Teletype's grammar and many of its words, but it is not a Teletype. Teletype's CV and trigger words (CV, TR) are not here; TELEX plays MIDI notes and CC instead. Teletype scenes and monome's Teletype tutorials translate almost line for line once those are swapped.
