The Box

A desktop box of TELEX's own. It plays samples, sends and receives MIDI, has stereo audio in and out, and takes a USB keyboard. This page describes where the hardware should end up.

If you build hardware: the diagrams show the plan, and the open questions at the end are the calls someone who builds hardware would make better than we would.

Why a box

TELEX runs today as custom firmware on an original Polyend Tracker. You type short scripts; each scene has ten of them. Scripts 1 to 8 run when triggered, M runs on a metro, and I runs when the scene loads. Around the scripts sit four LFOs and four clocks that fire them, a small test synth, sample instruments loaded from the card, MIDI notes and CC out, and a USB console. Through the console a computer, including Claude, can read and rewrite scripts while the box keeps playing.

All of that works on the Tracker now, MIDI over DIN and USB included. The Tracker's chip, keys and I/O set the limits: a 180 MHz CPU shared between the scripts, the sample voices and the effects, and a pad grid standing in for a keyboard. A box of its own adds more CPU, a real keyboard, and audio in and out. The emulator runs the same firmware in a browser.

What it does

5″, 800 × 480, the same layout as on the Tracker
Samples
A library on microSD, with more voices than the Tracker can run
Console
USB-C to a computer: live script editing, plus USB MIDI
Keyboard
Any USB keyboard, through a small hub
MIDI
5-pin DIN in and out, plus USB MIDI gear on the hub
Audio
Stereo line in, stereo line out, headphones
Power
One 5 V, 3 A supply

The brain: Teensy 4.1

  • CPU. A 600 MHz Cortex-M7, against the Tracker's 180 MHz K66. That headroom is where the extra sample voices come from.
  • Same codec. The Teensy Audio Shield uses the SGTL5000, the same codec as the Tracker.
  • Same display family. The Tracker drives an FT812 EVE chip; the box uses a BT817 from the same family, so the drawing code carries over.
  • Memory. 16 MB of PSRAM for samples, bought already fitted (ProtoSupplies sells a "Fully Loaded" Teensy 4.1), so there's no fine-pitch soldering. The microSD slot is on the board.
  • Two USB ports. The device port carries the console and USB MIDI. A separate host port feeds the hub for the keyboard and MIDI gear.

The software port: TELEX sits on a hardware layer written for the Tracker's chip (audio, display, card, USB). That layer gets rewritten for the RT1062. The language, the engine and the screens move over as they are, the same way they already compile for the browser.

Power

One 5 V, 3 A supply feeds the Teensy, the display and the USB ports. The Teensy's VUSB–VIN pad is cut, so a computer on the console port and the supply never feed the same rail.

Build order

Each phase works on its own before the next starts.

  1. Bench core about $90–105

    Teensy, audio shield, MIDI and an encoder on a breadboard, no screen.

    Shows: TELEX ported and making sound, MIDI in and out, the console working.

  2. Screen about $95–130

    The 5″ EVE display on SPI, running the same screens as the Tracker.

    Shows: the display layer ported, editing on the box itself.

  3. The box about $85–170

    Power, the USB hub, panel sockets, keys and the enclosure.

    Shows: a closed box that runs without a computer attached.

Open questions

  1. Power input. A USB-C PD trigger board asking for 5 V, or a plain 5 V barrel jack? Which keeps hum out of the audio best at 3 A?
  2. Grounding. The box shares ground with the computer over USB and with the mixer over audio. Where does the star ground go, and is a USB isolator on the console port worth it?
  3. Display link. The EVE display runs on SPI over a ribbon. How long can that run at 20–30 MHz before it needs buffering or a slower clock?
  4. MIDI. 6N138 or H11L1 for MIDI in on a 3.3 V board? Full 5-pin DIN on the panel, or 3.5 mm TRS to save space?
  5. Panel keys. 20 mechanical switches: a scan matrix on GPIO, shift registers, or an I²C key controller?
  6. Enclosure. An off-the-shelf aluminium case, a 3D print, or laser-cut panels? Any boxes you've had good luck with?
