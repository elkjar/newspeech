Emulator

The box's own firmware, compiled to WebAssembly: the same screen, the same language and the same voice as on the Tracker. Type a line, press Enter, press F1.

Loading the box…

Keys

Click the screen first; keys reach the box while it has focus. Letters, digits and the script symbols type on the box's keyboard; you can also click or tap its keys on the screen, and the soft keys along the bottom.

Enter
Insert: enter the line
Backspace
Delete the letter before the cursor; with Shift, the whole line
F1–F8
Run scripts 1–8 (with Shift: init, undo, redo … out)
Tab Shift+Tab
The encoder: the next or previous script
arrows
Move the cursor and the line; with Shift, move the line itself
Esc
Play: start or stop the metro
Ctrl+Z Ctrl+Y
Undo, redo (the box's Shift+F2, F3)
Ctrl+C Ctrl+V
Copy the line, paste over it
Shift
The box's Shift, held while you hold it

What's different from the hardware: there are no sample instruments yet (INST plays nothing), no line input, and the CPU readout is the browser's, not the box's. Scenes you save on the SCENES page stay in this browser. MIDI out uses Web MIDI (Chrome, Edge, Safari 18+). The readme has every word.
