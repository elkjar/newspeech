To flash with dfu-util instead of the browser (connect USB before 9V, see below):

dfu-util -a 0 -D application_release_0_971_k_l_m_q….dfu

flash over usb

This browser has no WebUSB. Use Chrome or Edge on a desktop, or download the .dfu and use dfu-util.

  1. Take the backplate off.
  2. Connect USB (mini-B) to the jack beside the ribbon header.
  3. Plug in USB first, then 9V. That starts the chip's bootloader instead of the pedal.
  4. Connect, back up, then flash. When it's done, unplug USB and 9V and power up normally.

Windows: the bootloader needs the WinUSB driver (install it with Zadig) before the browser can see it. macOS and Linux need nothing.
