texture

a loop mangler in the browser — drop any audio file, select the slice you want, pull it apart: vari-speed tape, a granular cloud, a self-oscillating noise filter.

print the result as a longer texture wav — one full pass at whatever speed you've bent it to.

open texture

slice

a pattern slicer — type a message and it plays as morse rhythm, locked to a clock you set. run the internal tone, or drop a loop and let the phrase gate, chop, or scan it.

a mangle stage flips, ratchets, and drops symbols — or scrambles the message itself pass by pass until it erodes into noise. feed it a dataset and the numbers play instead.

open slice

decay

disintegration loops — drop a loop and let the tape rot. wear lands where it already hurts, pass after pass: dropouts, stutters, muffled patches, until the loop plays itself to silence.

nothing is immediate; everything accumulates. print the whole collapse as one wav — a handful of passes, or the full run to silence.

open decay

drone

a breathing drone instrument — one tone, six harmonics, each swelling on its own slow clock, never twice the same balance. twist the spectrum, the width, the breath; reroll the seed for a new performance of the same tone.

when it's right, export the kit: nine note-named single-tone wavs, seamless loops — built for sequence's pad instruments, ready for any sampler.

open drone

glitch

audio destruction — drop a wav, get a worse wav. six stages in a fixed order: crush, noise, drive, chop, glitch, feedback. draw blocks into the lanes to say where each one hits; every block carries its own settings.

every pass mutates what you drew. loop a region, lock the grid to the file's bpm, reseed for a random set. print the last pass, or the whole arc, as one wav.

open glitch

stretch

sampler timestretch — the old akai trick of splicing blocks in and out to change a loop's length without touching its pitch, pushed well past where it holds together. cyclic splices blind for the jungle warble; intell hunts for a cleaner landing point.

then out through a 12- or 8-bit converter — sample-and-hold down to 8k, no anti-aliasing, no dither. drag a loop on the wave, audition it live, print one pass as a wav; the filename carries the new bpm.

open stretch

samples

the newspeech sample library — kits recorded from the rack, sliced and note-named for hardware and software samplers.

audition every hit in the browser, pull single files or zip whole packs. free under cc by-sa 4.0.

open the library
